# Frontend design

For work not governed by an existing brand or design system.

## Think before coding

- Purpose: what problem does this interface solve, and who uses it?
- Tone: pick an extreme and commit. Brutally minimal, maximalist, retro-futuristic, organic, luxury, toy-like, editorial, brutalist, art deco, pastel, industrial. Use these as starting points and design one that is true to the direction.
- Differentiation: what makes this unforgettable? What is the one thing someone will remember?

Bold maximalism and refined minimalism both work. Intentionality matters, not intensity.

## Aesthetics

- **Typography**: beautiful, unique, characterful. Avoid Arial, Inter, Roboto. Pair a distinctive display face with a refined body face.
- **Color**: commit to a cohesive palette with variables for consistency. Dominant colors with sharp accents beat timid evenly-distributed palettes.
- **Motion**: effects and micro-interactions, CSS-first. Focus on high-impact moments; one well-orchestrated page load with staggered reveals delights more than scattered micro-interactions.
- **Composition**: unexpected layouts. Asymmetry, overlap, diagonal flow, grid-breaking elements. Either generous negative space or controlled density.
- **Backgrounds and detail**: atmosphere and depth rather than flat fills. Gradient meshes, noise, geometric pattern, layered transparency, dramatic shadow, decorative borders, grain.

Vary between light and dark, different fonts, different aesthetics. Never converge on the same choices twice.

Match implementation complexity to the vision: maximalist work needs elaborate animation and effects, minimalist work needs restraint, precision, and careful spacing.
